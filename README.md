# Epic Games Giveaway Analysis

Project by Dylan Bay

## Overview

This project analyzes all the free games and extra content given away by Epic since late 2018 through their storefront. With a minimum of one game per week given away since mid-2019, over 500 unique games have been given away throughout the lifetime of the giveaways, which continue through the present day. This represents an enormous and sustained investment in a multi-billion dollar market, but despite this very little detailed analysis has been done on this rich dataset. 

This project compiles data from community-maintained lists, Wikipedia, various industry websites such as HowLongToBeat and Metacritic, as well as from the Epic Games storefront itself to produce a clean and rich dataset for analysis. 

The eventual objective is to provide further structured visualization, analysis, and modeling using this dataset and additionally provide an interactive data viewer for end users to explore the dataset in more detail.
